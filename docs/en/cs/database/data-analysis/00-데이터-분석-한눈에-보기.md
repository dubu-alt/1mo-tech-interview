This page gathers in one place the concepts that appear in the Codyssey AI Advanced A1-1 mission, "Find loyal customers by analyzing who visits often and buys a lot at an online store." Skim the overall flow and concepts here first, and see each concept's article for details.

## Analysis Flow

```
Load
 → Explore (EDA, descriptive statistics)
 → Preprocess (missing value imputation, IQR outliers, clipping)
 → Feature engineering (images and text into numeric columns)
 → Statistics & visualization (correlation coefficient, 6 chart types)
 → Customer segmentation (RFM, cohorts)
 → Insights (evidence, action, validation)
```

## What A1-1 Left Behind

| Item | Details |
|---|---|
| Data | 1,067,371 transactions over 2 years from a UK online gift shop (Online Retail II) + 60,000 practice clothing images (Fashion-MNIST) |
| Tools | NumPy, Pandas, Matplotlib, Seaborn (without machine learning or image-specific libraries) |
| Cleaning result | 1,007,913 rows (5.6% removed) |
| Deliverables | `DataAnalyzer` class (`src/pipeline.py`), analysis notebook, README with 4 insights |
| Key results | 21.7% of customers (VIP) account for 68% of purchase amount, 39.9% of customers have churned, sales are concentrated in October and November |
| Biggest limitation | Original orders that were later canceled remain in the data, so some customers' purchase amounts may be inflated |
