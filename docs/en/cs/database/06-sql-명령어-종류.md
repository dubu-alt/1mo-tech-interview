SQL commands are divided by what they do, as follows.

| Category | Meaning | In this project |
|---|---|---|
| DDL (Data Definition Language) | Defines table structure | `CREATE TABLE`, `CREATE INDEX`, `DROP TABLE` -> `01_schema.sql` |
| DML (Data Manipulation Language) | Manipulates data | `INSERT`, `UPDATE`, `DELETE` -> `02_sample_data.sql`, Q15/Q16 in `03_queries.sql` |
| DQL (Data Query Language) | Queries data | `SELECT` -> most of `03_queries.sql` |

## Summary

- DDL defines structure (`CREATE`/`DROP`), DML manipulates data (`INSERT`/`UPDATE`/`DELETE`), and DQL queries data (`SELECT`).
