# GitHub Repository 환경설정

프로젝트 상단바의 **Settings**에서 저장소 전반의 규칙을 설정할 수 있습니다. (Settings가 안 보인다면 권한이 없는 것이니 요청해서 받으면 됩니다.) 좌측 네비게이션의 **General** 메뉴에서 중요한 설정 세 가지를 짚어보겠습니다.

## Default Branch

PR을 만들 때 기본으로 머지 대상이 되는 브랜치입니다. 보통 `main`으로 설정돼 있지만, 필요하다면 `develop` 등으로 바꿀 수 있습니다. 바꾸면 이후 생성되는 PR은 새 기본 브랜치로 머지를 요청하게 됩니다.

## PR 머지 종류 제한하기

앞서 다룬 Merge Commit / Squash / Rebase 세 가지 중 특정 방식만 쓰도록 강제할 수 있습니다. 팀의 머지 정책을 통일하고 싶을 때, 특히 깔끔한 히스토리를 유지하고 싶을 때 유용합니다.

## 머지 후 브랜치 자동 삭제

PR용으로 만든 브랜치는 대부분 일회성입니다. 이 옵션을 켜두면 PR이 머지되는 순간 해당 브랜치가 자동으로 삭제되어, 안 쓰는 브랜치를 일일이 정리하는 수고를 덜 수 있습니다.
