---
title: "Fork와 오픈소스 기여"
---

**Fork**는 Git 자체의 기능이 아니라 GitHub 같은 호스팅 서비스가 제공하는 기능입니다. **이미 존재하는 원격 repository를 내 계정으로 통째로 복사**해오는 것이죠. 복사된 repository는 원본과 완전히 분리되어 있어서, 내 마음대로 변경 사항을 반영할 수 있고 원한다면 PR로 원본에 기여할 수도 있습니다.

## 왜 브랜치가 아니라 Fork를 쓸까?

브랜치 방식은 원본 저장소에 직접 접근해 작업하고 바로 PR을 올리는 방식입니다. 팀 규모가 적당하면 이 방식이 효율적이죠.

반면 오픈소스처럼 **누가 참여할지 모르는 대규모 프로젝트**에서는 아무나 원본 저장소에 브랜치를 만들 권한을 줄 수 없습니다. 그래서 각자 자기 Fork에서 자유롭게 작업하고, 완성되면 원본 소유자에게 PR로 제안하는 방식을 씁니다. 심리적 부담도 훨씬 적습니다.

## Fork로 PR 만드는 순서

1. 원하는 프로젝트 페이지로 이동
2. 우측 상단 `Fork` 버튼 클릭 → 내 계정으로 복사
3. Fork된 저장소에서 브랜치 생성
4. 변경 사항 커밋 & 푸시
5. Fork된 저장소에서 `New pull request` 클릭
6. 반영할 원본 저장소/브랜치 선택
7. PR 작성 후 제출

## 오픈소스에 기여해보기

기여 방법은 생각보다 다양합니다. 버그 리포트, 문서 개선, 테스트 작성은 막 시작한 사람도 접근하기 쉬운 방법입니다. GitHub의 **Good First Issue** 라벨을 찾아보면 초보자도 도전할 만한 이슈들을 모아볼 수 있습니다. [goodfirstissue.dev](https://goodfirstissue.dev/) 같은 사이트에서 원하는 언어로 필터링해서 첫 기여를 시도해볼 수 있습니다.
