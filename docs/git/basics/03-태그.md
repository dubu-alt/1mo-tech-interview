> git tag  

프로젝트 디렉토리에 있는 모든 태그 조회

![](/images/git/cd114de1506b.png)

> git show [태그 이름]

각 태그와 연결된 커밋을 볼수 있음

![](/images/git/cf8c3beec63c.png)

## 정리

| 명령어 | 하는 일 |
| --- | --- |
| `git tag [태그 이름] [커밋 아이디]` | 특정 커밋에 태그 붙이기 |
| `git tag` | 모든 태그 조회 |
| `git show [태그 이름]` | 태그와 연결된 커밋 보기 |

> 참고: 개인 Notion 학습 노트 (Git 공부)
