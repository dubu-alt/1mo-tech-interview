# 한 줄 요약

| 개념 | 비전공자 버전 요약 |
|------|-------------------|
| O(1) | 데이터가 많아져도 즉시 처리 |
| 이중 연결 리스트 | 앞뒤 손잡이가 달린 줄. 줄 순서 바꾸기가 즉석(O(1)) |
| 해시맵 | 이름표 계산으로 바로 찾아가는 창고. 충돌 시 방 안에 줄 세우기(체이닝) |
| 최소 힙 | 제일 작은/급한 게 항상 맨 위에 있는 피라미드 |
| LRU | 안 쓴 지 제일 오래 된 것부터 버리기 (해시맵+연결리스트 조합) |
| TTL | 데이터 유통기한. 만료 예약은 힙으로 관리 |
| REPL | 입력→실행→출력 무한 반복 대화창 |
