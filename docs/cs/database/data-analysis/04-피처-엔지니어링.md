이미지와 텍스트처럼 바로 계산할 수 없는 데이터를 숫자 열로 바꾸는 과정을 정리했습니다.

## 피처와 파생 변수

<strong>피처(feature)</strong>는 분석이나 모델에 넣는 열 하나하나, 곧 변수입니다. **피처 엔지니어링**은 원본 데이터에서 쓸모 있는 새 피처를 만드는 일이고 이렇게 만든 열을 **파생 변수**라고 부릅니다. 모델은 숫자만 다룰 수 있어서 텍스트, 이미지, 날짜를 숫자로 바꾸는 작업이 큰 비중을 차지합니다.

| 원본 | 만든 피처 | 방법 |
|---|---|---|
| 이미지 (28×28 배열) | `img_mean`, `img_std` | 이미지마다 픽셀 밝기의 평균, 표준편차 |
| 상품명 (텍스트) | `name_word_count`, `name_length` | 단어 수, 글자 수 |
| 수량, 단가 | `amount` | 수량 × 단가 = 주문 금액 |
| 주문일 (날짜) | `recency` | 기준일 - 마지막 구매일 (일수) |

## 이미지를 숫자로 바꾸기

흑백 이미지 한 장은 28×28 칸에 0(검정)부터 255(흰색)까지의 밝기 값이 들어 있는 표입니다. 6만 장을 모으면 `(60000, 28, 28)` 모양의 3차원 배열이 됩니다.

![Fashion-MNIST 이미지 12장과 각 이미지의 평균 밝기, 그리고 이미지 한 장의 픽셀 값 일부](/images/database/fashion-mnist-preview.png)
*그림: A1-1 저장소의 이미지 데이터 미리보기. 데이터 출처: [Fashion-MNIST](https://github.com/zalandoresearch/fashion-mnist) (MIT)*

그림 위의 `mean` 값이 이미지 한 장의 평균 밝기입니다. 평균은 옷이 전체적으로 밝은지 어두운지를, 표준편차는 명암 대비가 얼마나 큰지를 나타냅니다.

```python
images.shape                    # (60000, 28, 28)
images.mean(axis=(1, 2))        # 이미지마다 28×28 칸을 평균 → 길이 60000짜리 배열
images.std(axis=(1, 2))         # 이미지마다 표준편차
```

`axis=(1, 2)`는 세로·가로 방향을 묶어서 계산하라는 뜻입니다. 첫 번째 축(이미지 번호)은 남기고 나머지를 줄이니 이미지마다 값이 하나씩 나옵니다.

## 면접에서 나올 만한 질문

### Q. 피처 엔지니어링이 무엇이고 이미지에서는 어떤 피처를 뽑았나요?

용어를 아는지보다 원본 데이터를 어떻게 숫자로 바꿨는지 설명할 수 있는지 봅니다.

> 피처는 분석이나 모델에 넣는 변수이고 피처 엔지니어링은 원본 데이터에서 쓸모 있는 변수를 새로 만드는 일입니다. 모델은 숫자만 다루기 때문에 텍스트와 이미지를 숫자로 바꿔야 합니다. A1-1에서는 28×28 이미지를 픽셀 밝기의 평균과 표준편차 두 숫자로 줄였고, 상품명은 단어 수와 글자 수로 바꿨습니다. 다만 이미지를 상품에 무작위로 붙였기 때문에 이 피처와 구매 금액의 상관계수는 -0.012로 거의 없었고, 인사이트에는 쓰지 않았습니다.
