코디세이 AI 심화 A1-1 미션 「쇼핑몰에서 누가 자주 오고 많이 사는지 분석해서 단골 찾기」에 나오는 개념을 한 묶음으로 정리했습니다. 이 페이지에서 전체 흐름과 개념을 먼저 훑고, 자세한 내용은 개념별 글에서 보면 됩니다.

## 분석 흐름

```
불러오기
 → 탐색 (EDA, 기술 통계)
 → 전처리 (결측치 대치, IQR 이상치, 클리핑)
 → 피처 엔지니어링 (이미지·텍스트를 숫자 열로)
 → 통계·시각화 (상관계수, 차트 6종)
 → 고객 세분화 (RFM, 코호트)
 → 인사이트 (근거·실행·검증)
```

## 개념 한 줄 정리

| 개념 | 한 줄 뜻 | 자세히 |
|---|---|---|
| NumPy | 숫자 배열을 반복문 없이 한 번에 계산하는 라이브러리 | [NumPy와 Pandas](./01-numpy와-pandas) |
| Pandas | 표 데이터를 읽고 정제하고 그룹별로 집계하는 라이브러리 | [NumPy와 Pandas](./01-numpy와-pandas) |
| 벡터 연산 | `for` 문 대신 배열 전체에 연산을 한 번에 적용하는 방식 | [NumPy와 Pandas](./01-numpy와-pandas) |
| 멀티모달 데이터 | 숫자, 글자, 날짜, 이미지처럼 형태가 다른 데이터가 섞여 있는 것 | [EDA와 기술 통계](./02-eda와-기술-통계) |
| EDA | 결론을 내기 전에 데이터를 요약하고 그려 보며 특징을 파악하는 단계 | [EDA와 기술 통계](./02-eda와-기술-통계) |
| 기술 통계 | 평균, 중앙값, 표준편차, 사분위수로 데이터를 요약하는 것 | [EDA와 기술 통계](./02-eda와-기술-통계) |
| 그룹별 결측치 대치 | 빈칸을 비슷한 행끼리 묶은 그룹의 통계값으로 채우는 것 | [결측치와 이상치](./03-결측치와-이상치) |
| IQR 이상치 | 가운데 50% 범위(IQR)의 1.5배 바깥에 있는 값 | [결측치와 이상치](./03-결측치와-이상치) |
| 클리핑 | 이상치를 지우지 않고 경계값으로 눌러 두는 것 | [결측치와 이상치](./03-결측치와-이상치) |
| 피처 엔지니어링 | 원본 데이터에서 분석에 쓸 새 열(파생 변수)을 만드는 일 | [피처 엔지니어링](./04-피처-엔지니어링) |
| 상관계수 | 두 변수가 함께 움직이는 정도를 -1~1로 나타낸 값 | [상관계수와 시각화](./05-상관계수와-시각화) |
| 시각화 6종 | 히스토그램, 박스플롯, 막대그래프, 히트맵, 산점도, 라인차트 | [상관계수와 시각화](./05-상관계수와-시각화) |
| 고객 세분화 | 비슷하게 행동하는 고객끼리 묶어 그룹마다 다르게 대응하는 것 | [RFM과 고객 세분화](./06-rfm과-고객-세분화) |
| RFM | 최근성(R), 빈도(F), 금액(M)으로 고객에게 점수를 매겨 나누는 방법 | [RFM과 고객 세분화](./06-rfm과-고객-세분화) |
| 코호트 분석 | 같은 시기에 처음 온 고객끼리 묶어 시간이 지나며 얼마나 남는지 보는 방법 | [RFM과 고객 세분화](./06-rfm과-고객-세분화) |
| 근거·실행·검증 | 인사이트를 숫자 근거, 실행 계획, 틀릴 수 있는 경우로 나눠 쓰는 형식 | [인사이트와 분석의 한계](./07-인사이트와-분석의-한계) |
| 파이프라인 클래스 | 분석 단계를 메서드로 묶어 다시 쓸 수 있게 만든 클래스 | [인사이트와 분석의 한계](./07-인사이트와-분석의-한계) |

## A1-1에서 남긴 것

| 항목 | 내용 |
|---|---|
| 데이터 | 영국 온라인 선물용품 쇼핑몰의 2년치 거래 1,067,371건(Online Retail II) + 연습용 옷 이미지 60,000장(Fashion-MNIST) |
| 도구 | NumPy, Pandas, Matplotlib, Seaborn (머신러닝·이미지 전용 라이브러리 없이) |
| 정제 결과 | 1,007,913행 (5.6% 제거) |
| 결과물 | `DataAnalyzer` 클래스(`src/pipeline.py`), 분석 노트북, 인사이트 4개를 담은 README |
| 핵심 결과 | 고객 21.7%(VIP)가 구매 금액의 68%, 고객 39.9%는 이탈 상태, 매출은 10~11월에 집중 |
| 가장 큰 한계 | 취소된 원래 주문이 남아 일부 고객의 구매 금액이 부풀려졌을 수 있음 |
