---
title: "ERD 표기법: 까마귀발(Crow's Foot)"
---

**ERD(Entity Relationship Diagram)**는 엔터티와 관계를 그림으로 표현한 것입니다. 표기법은 여러 종류가 있지만(Peter Chen, 정보공학, Ellis-Barker, IDEF1X, UML 등), 실무와 툴에서 가장 흔히 쓰이는 건 **IE(Information Engineering) Crow's Foot**, 일명 "까마귀발" 표기법입니다.

엔터티는 직사각형(표)으로 그리고, 표 위 칸에 엔터티 이름을, 첫 행에 식별자(PK)를 적습니다.

```
┌────────────┐
│   사원      │  ← 엔터티 이름
├────────────┤
│ *사원번호   │  ← 식별자(PK)
│  이름       │
│  부서번호   │
└────────────┘
```

관계선 끝에 붙는 기호가 "까마귀 발자국"처럼 갈라져 있다고 해서 붙은 이름입니다. 기호 하나로 **몇 개까지(차수)**와 **꼭 있어야 하는지(선택성)**를 동시에 표현합니다.

```
──○<   0개 또는 여러 개 (선택 + 다수)
──│<   1개 이상 (필수 + 다수)
──○|   0개 또는 1개 (선택 + 단수)
──||   반드시 1개 (필수 + 단수)
```

예를 들어 `부서 ──|| ──< 사원` 이라고 그리면, "사원은 반드시 부서에 1개 속하고, 부서는 사원을 0명 이상 가질 수 있다"는 뜻입니다.

이 외에 Peter Chen 표기법(엔터티는 사각형, 관계는 마름모로 따로 그림), IDEF1X(식별/비식별 관계를 실선/점선으로 엄격히 구분), UML 클래스 다이어그램 스타일 표기법 등도 있는데, 전달하려는 정보(엔터티/속성/관계/차수/선택성)는 결국 같고 그림으로 그리는 방식만 다릅니다.
