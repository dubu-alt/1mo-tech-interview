실행 중인 프로세스(PID)를 확인하는 방법과, 그 프로세스가 열어 둔 네트워크 포트를 확인하는 방법을 함께 정리했다.

## 프로세스 관리 (PID)

### 개념

프로세스는 실행 중인 프로그램이다. 각 프로세스에는 고유한 PID(Process ID) 번호가 부여된다.

### 주요 명령어

```bash
# 전체 프로세스 목록
ps aux

# 특정 프로세스 검색
ps aux | grep agent_app.py

# 프로세스 종료
kill <PID>
kill -9 <PID>    # 강제 종료

# 실시간 프로세스 모니터링
top
htop
```

### monitor.sh에서 활용하는 방법

```bash
PID=$(pgrep -f agent_app.py)

if [ -z "$PID" ]; then
    echo "[ERROR] 프로세스가 실행 중이지 않습니다."
    exit 1
fi
```

## 네트워크와 포트

### 개념

포트는 네트워크 통신의 문(door)이다. 서버는 특정 포트를 열고 연결을 기다린다(LISTEN). 클라이언트는 해당 포트로 접속한다.

### 주요 명령어

```bash
# 열려 있는 포트 확인
ss -tulnp

# 출력 예시
# tcp  LISTEN  0  128  0.0.0.0:15034  ...  python3

# 특정 포트 확인
ss -tulnp | grep 15034
```

### ss 출력 해석

| 컬럼 | 의미 |
| --- | --- |
| State | LISTEN = 연결 대기 중 |
| Local Address:Port | 서버가 열어 놓은 주소:포트 |
| 0.0.0.0 | 모든 네트워크 인터페이스에서 수신 |

## 정리

| 항목 | 명령어 | 비고 |
| --- | --- | --- |
| 프로세스 목록/검색 | `ps aux`, `ps aux \| grep agent_app.py` | 각 프로세스는 고유 PID 보유 |
| 프로세스 종료 | `kill <PID>`, `kill -9 <PID>` | `-9` 는 강제 종료 |
| 실시간 모니터링 | `top`, `htop` | |
| 스크립트에서 PID 얻기 | `pgrep -f agent_app.py` | 비어 있으면 `exit 1` |
| 열린 포트 확인 | `ss -tulnp` | `LISTEN` = 연결 대기 중, `0.0.0.0` = 모든 인터페이스 |
