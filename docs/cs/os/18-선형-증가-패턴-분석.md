### 이 문서에서 관찰된 패턴의 의미

```
메모리(MB)
100 |                    ●  ← 종료
 75 |               ●
 50 |          ●
 25 |     ●
  0 +----+----+----+----+
    0    3    6    9   (초)

기울기 = 25MB / 3초 ≈ 8.3MB/초
→ 일정한 기울기 = 규칙적인 누수
→ 랜덤하지 않음 = 의도된 동작 or 반복 루프
```

> **패턴으로 알 수 있는 것**
> - **랜덤 누수**: 불규칙한 증가 → 버그성 누수
> - **선형 누수 (이 경우)**: 규칙적 증가 → 반복 루프에서 해제 없이 할당

```python
# 추정되는 내부 동작 (의사 코드)
def memory_worker():
    while True:
        data = allocate(25 * MB)  # 할당
        # free(data) ← 이게 없음!
        time.sleep(3)             # 3초 대기
```
