# 전체 개념 연결 지도

```
MULTI_THREAD_ENABLE=True
        │
        ▼
  멀티스레드 환경
        │
        ├──→ 데드락 위험 ⚠️
        │
        └──→ 여러 스레드가 Heap 동시 접근
                    │
                    ▼
              메모리 누수 (Memory Leak)
              [malloc은 있고 free는 없음]
                    │
                    ▼
              Heap 선형 증가
              (3초마다 +25MB)
                    │
                    ▼
              MEMORY_LIMIT 도달
              (100MB >= 100MB)
                    │
                    ▼
              MemoryGuard 발동
                    │
                    ▼
              SIGKILL → OOM 
```
