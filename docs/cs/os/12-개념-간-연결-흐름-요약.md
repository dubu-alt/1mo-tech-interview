title: "개념 간 연결 흐름 요약"
---

```
계정/그룹 분리
    └── 파일 권한 + ACL 적용
            └── monitor.sh 소유/실행 권한 제어
                    └── cron이 agent-admin으로 매분 실행
                            └── 프로세스/포트/리소스 수집
                                    └── /var/log/agent-app/monitor.log 기록
                                            └── logrotate로 용량 관리
```

SSH 보안과 방화벽은 이 흐름의 바깥에서 **외부 접근 자체를 제어**하는 레이어다.
