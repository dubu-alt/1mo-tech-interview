## 함수란?

**정의**: 특정 작업을 수행하는 **재사용 가능한 코드 묶음**

**왜 사용하는가?**

- 같은 코드를 여러 번 반복해서 쓸 필요 없음
- 코드의 가독성과 유지보수성 향상
- 복잡한 문제를 작은 단위로 나눠 해결 가능

## 함수 정의와 호출

**기본 구조**

```python
def 함수이름(매개변수):
    # 함수가 할 일
    return 반환값
```

**예시**

```python
# 함수 정의
def add(a, b):
    result = a + b
    return result

# 함수 호출
answer = add(3, 5)
print(answer)           # 출력: 8
```

## 매개변수와 반환값

- **매개변수(parameter)**: 함수에 입력으로 받는 값
- **반환값(return value)**: 함수가 출력하는 값

```python
# 매개변수 2개, 반환값 1개
def multiply(a, b):
    return a * b

result = multiply(4, 5)
print(result)           # 출력: 20

# 반환값이 없는 경우
def greet(name):
    print(f"안녕하세요, {name}님!")

greet("철수")           # 출력: 안녕하세요, 철수님!

# 매개변수가 없는 경우
def get_today():
    return "2024년 1월 15일"

print(get_today())      # 출력: 2024년 1월 15일
```

## 기본값 설정

매개변수에 기본값을 정해 두면, 호출할 때 그 값을 생략할 수 있습니다.

```python
def introduce(name, age=20):
    print(f"안녕하세요, 저는 {name}이고 {age}살입니다")

introduce("철수")       # 출력: 안녕하세요, 저는 철수이고 20살입니다
introduce("영희", 25)   # 출력: 안녕하세요, 저는 영희이고 25살입니다
```

## 정리

| 개념 | 요약 |
| --- | --- |
| 함수 | 재사용 가능한 코드 묶음 → 코드 재사용성 증대 |
| 매개변수 | 함수에 입력으로 받는 값 → 같은 함수를 다른 값으로 실행 |
| 반환값 | 함수가 돌려주는 결과 → 결과를 변수에 담아 다시 사용 |
