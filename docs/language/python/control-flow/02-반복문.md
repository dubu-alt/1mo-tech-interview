## for문 vs while문 한눈에 보기

| 특징 | for | while |
| --- | --- | --- |
| 횟수 | 정해짐 | 정해지지 않음 |
| 사용 시기 | 리스트, range 순회 | 조건 체크하며 반복 |
| 문법 | `for item in list:` | `while 조건:` |
| 예시 | 리스트의 모든 원소 출력 | 입력 받을 때까지 반복 |

## for 반복문

**정의**: **정해진 횟수만큼** 코드를 반복 실행하는 문장

**특징**

- 횟수가 정해져 있을 때 사용
- 리스트, 문자열 등을 순회할 때 유용

**예시 1: 리스트 반복**

```python
fruits = ["사과", "바나나", "딸기"]

for fruit in fruits:
    print(fruit)

# 출력:
# 사과
# 바나나
# 딸기
```

**예시 2: range() 이용**

```python
# range(5) = 0, 1, 2, 3, 4
for i in range(5):
    print(i)

# 출력: 0 1 2 3 4

# range(1, 6) = 1, 2, 3, 4, 5
for i in range(1, 6):
    print(i)

# 출력: 1 2 3 4 5
```

**예시 3: 딕셔너리 반복**

```python
student = {"name": "철수", "age": 25, "grade": "A"}

for key in student:
    print(f"{key}: {student[key]}")

# 출력:
# name: 철수
# age: 25
# grade: A
```

## while 반복문

**정의**: **조건이 참인 동안** 코드를 반복 실행하는 문장

**특징**

- 반복 횟수가 정해지지 않을 때 사용
- 조건이 거짓이 될 때까지 계속 반복
- 무한 루프 주의

```python
count = 0

while count < 5:
    print(count)
    count += 1

# 출력: 0 1 2 3 4

# 입력받을 때까지 반복
while True:
    answer = input("종료하시겠습니까? (yes/no): ")
    if answer == "yes":
        break  # 반복 종료
    else:
        print("계속합니다")
```

## 정리

| 개념 | 요약 |
| --- | --- |
| for | 정해진 횟수 반복 → 리스트 순회 |
| while | 조건 확인하며 반복 → 입력 받을 때까지 반복 |

> 참고: 개인 Notion 학습 노트 (입학연수 과정)
