**정의**: 주어진 조건에 따라 **다른 코드를 실행**하도록 제어하는 문장

**구조**

```text
if 조건1:
    (조건1이 참일 때 실행)
elif 조건2:
    (조건1은 거짓, 조건2가 참일 때 실행)
else:
    (모든 조건이 거짓일 때 실행)
```

**예시**

```python
score = 85

if score >= 90:
    print("A학점")
elif score >= 80:
    print("B학점")
elif score >= 70:
    print("C학점")
else:
    print("F학점")

# 출력: B학점
```

## 비교 연산자

| 연산자 | 의미 | 예시 |
| --- | --- | --- |
| `==` | 같다 | `5 == 5` → True |
| `!=` | 다르다 | `5 != 3` → True |
| `>` | 크다 | `5 > 3` → True |
| `<` | 작다 | `5 < 3` → False |
| `>=` | 크거나 같다 | `5 >= 5` → True |
| `<=` | 작거나 같다 | `5 <= 3` → False |

## 논리 연산자

| 연산자 | 의미 | 예시 |
| --- | --- | --- |
| `and` | 그리고 (둘 다 참) | `(5 > 3) and (3 > 1)` → True |
| `or` | 또는 (하나라도 참) | `(5 > 10) or (3 > 1)` → True |
| `not` | 반대 | `not True` → False |

**조건문 활용 예시**

```python
age = 20
has_license = True

if age >= 18 and has_license:
    print("운전 가능합니다")
else:
    print("운전할 수 없습니다")

# 출력: 운전 가능합니다
```

## 정리

| 개념 | 요약 |
| --- | --- |
| if/elif/else | 조건에 따른 분기 → 상황에 따라 다른 동작 |
| 비교 연산자 | `==` `!=` `>` `<` `>=` `<=` 로 두 값을 비교 |
| 논리 연산자 | `and` `or` `not` 으로 조건을 조합 |
