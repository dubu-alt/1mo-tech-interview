## list (리스트)

**정의**: 여러 개의 값을 **순서 있게** 저장하는 자료형. 대괄호 `[]`로 표현합니다.

**특징**

- 순서가 있음 (인덱싱 가능)
- 수정 가능 (mutable)
- 다양한 자료형을 함께 저장 가능
- 중복된 값 허용

```python
fruits = ["사과", "바나나", "딸기"]
numbers = [1, 2, 3, 4, 5]
mixed = [1, "철수", 3.14, True]

print(fruits[0])                # 출력: 사과 (0번 인덱스)
print(fruits[-1])               # 출력: 딸기 (마지막 요소)
print(len(fruits))              # 출력: 3 (리스트 길이)

# 리스트 수정
fruits.append("포도")           # 끝에 추가
fruits.remove("바나나")         # "바나나" 제거
fruits[0] = "귤"                # 첫 번째 요소 변경

print(fruits)                   # 출력: ['귤', '딸기', '포도']
```

## dict (딕셔너리)

**정의**: 키(key)와 값(value)의 쌍으로 데이터를 저장하는 자료형. 중괄호 `{}`로 표현합니다.

**특징**

- 순서를 보장하지 않음 (**Python 3.7 이상부터는 넣은 순서가 유지됨**)
- 키로 값에 접근 (인덱싱과 다름)
- 키는 중복 불가, 값은 중복 가능
- 수정 가능 (mutable)

```python
student = {
    "name": "철수",
    "age": 25,
    "grade": "A",
    "score": 95
}

print(student["name"])          # 출력: 철수
print(student["age"])           # 출력: 25

# 딕셔너리 수정/추가
student["age"] = 26             # 수정
student["major"] = "컴퓨터공학"  # 추가

print(student.keys())           # 출력: dict_keys(['name', 'age', 'grade', 'score', 'major'])
print(student.values())         # 출력: dict_values(['철수', 26, 'A', 95, '컴퓨터공학'])
```

## 정리

| 개념 | 요약 |
| --- | --- |
| list | 순서 있는 여러 값 저장 → 여러 데이터 관리 |
| dict | 키-값 쌍으로 저장 → 정보를 체계적으로 짝짓기 |
