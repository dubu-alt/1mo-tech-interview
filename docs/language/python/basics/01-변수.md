## 변수란?

**정의**: 데이터를 저장하는 "상자"와 같은 개념입니다. 프로그램에서 값을 재사용하고 관리하기 위해 사용합니다.

**왜 사용하는가?**

- 같은 데이터를 여러 번 반복해서 입력할 필요 없음
- 코드의 가독성과 유지보수성 향상
- 프로그램이 유연해짐

**변수 선언 예시**

```python
name = "철수"      # 변수 name에 "철수" 저장
age = 25           # 변수 age에 25 저장
score = 95.5       # 변수 score에 95.5 저장

print(name)        # 출력: 철수
print(age + 5)     # 출력: 30 (변수를 재사용)
```
