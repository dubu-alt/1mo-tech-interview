## str (문자열)

**정의**: 텍스트 데이터를 나타내는 자료형. 작은따옴표(`' '`) 또는 큰따옴표(`" "`)로 표현합니다.

**특징**

- 문자, 숫자, 특수문자 모두 포함 가능
- 문자열 연결(`+`), 반복(`*`) 가능
- **주의! 같은 기호여도 자료형마다 다르게 동작합니다.** 숫자처럼 보여도 따옴표 안에 있으면 문자열이라 `+`는 이어 붙이기가 되고, `"문자열" * 숫자`는 그 숫자만큼 반복해서 출력합니다.

```python
a = "1000"
b = "100"
name = "철수"
message = 'Hello, Python!'
phone = "010-1234-5678"

print(a + b)                    # 출력: 1000100 (숫자 덧셈이 아니라 이어 붙이기)
print(name * 3)                 # 출력: 철수철수철수
print(name + "입니다")          # 출력: 철수입니다
print("Ha" * 3)                 # 출력: HaHaHa
print(len(name))                # 출력: 2 (문자열 길이)
print(name[0])                  # 출력: 철 (인덱싱, 0번째 문자)
```

## 인덱싱과 슬라이싱

- **인덱싱**: 하나의 값만 꺼내기. 인덱스는 **0부터** 시작합니다.
- **슬라이싱**: 여러 개를 잘라서 가져오기. `[시작:끝]`에서 **끝 위치는 포함하지 않습니다** (끝-1까지).

```python
# 인덱싱 예시
arr = [10, 20, 30, 40]

print(arr[0])   # 10 출력
print(arr[1])   # 20 출력

print(arr[-1])  # 40 (마지막)
print(arr[-2])  # 30

s = "hello"     # 문자도 가능

print(s[0])     # h 출력
print(s[1])     # e 출력
```

```python
# 슬라이싱 예시
sold = "5 300"               # 주의! 이건 문자열임
sold_mount = int(sold[2:5])  # 2번부터 4번까지 (5는 포함 안 됨)
print(sold_mount)            # 300 출력

arr = [10, 20, 30, 40, 50]

print(arr[0:3])  # [10, 20, 30] 출력
print(arr[:3])   # 처음 ~ 2번
print(arr[2:])   # 2번부터 끝까지

s = "hello"
print(s[1:4])    # ell 출력

arr = [1, 2, 3, 4, 5]
print(arr[::2])  # [1, 3, 5] 2칸씩 건너뛰어서 출력
```

## 정리

| 개념 | 요약 |
| --- | --- |
| str | 문자열 자료형 → 텍스트 데이터 |
| 인덱싱 | 하나의 값만 꺼내기, 0부터 시작 |
| 슬라이싱 | `[시작:끝]`으로 여러 개 잘라 오기, 끝 위치는 포함 안 됨 |
