## int (정수)

**정의**: 소수점이 없는 정수를 나타내는 자료형

**특징**

- 양수, 음수, 0을 표현 가능
- 사칙연산 가능 (`+`, `-`, `*`, `/`)

```python
age = 25
score = 100
negative = -10

print(type(age))        # 출력: <class 'int'>
print(score + 10)       # 출력: 110
print(score // 3)       # 출력: 33 (정수 나눗셈)
```

## bool (불린/논리값)

**정의**: `True`(참) 또는 `False`(거짓) 두 가지 값만 가지는 자료형

**특징**

- 조건 비교의 결과로 자주 사용됨
- `True`는 1, `False`는 0으로도 인식

```python
is_student = True
is_adult = False

print(type(is_student))         # 출력: <class 'bool'>
print(5 > 3)                    # 출력: True
print(10 == 5)                  # 출력: False
print(bool(0))                  # 출력: False
print(bool(1))                  # 출력: True
```

## 정리

| 개념 | 요약 |
| --- | --- |
| int | 정수 자료형 → 숫자 계산 |
| bool | True/False 자료형 → 조건 표현 |
